# Linux Workstation Automation

Conjunto de scripts modulares em **Bash** desenvolvidos para automatizar o setup de ambientes de desenvolvimento em distribuições baseadas em **Arch** e **Debian**[cite: 2].

## ✨ Funcionalidades:
*   **Instalação Automatizada:** Suporte para gerenciadores `pacman`, `apt`, `yay` e `flatpak`[cite: 2].
*   **Setup Reprodutível:** Configuração rápida de pacotes e ferramentas essenciais após formatação[cite: 2].
*   **Ambiente Dev:** Instalação de compiladores, editores e utilitários de sistema[cite: 2].

## Como modificar?
para adicionar mais softwares basta colocar o nome do pacote na lista do seus respectivo gerenciador de pacotes.

## 🔧 Uso:
```bash
chmod +x nome-script.sh
./nome-script.sh
